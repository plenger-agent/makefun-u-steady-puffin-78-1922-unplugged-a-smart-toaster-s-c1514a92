One line, under 280 characters: the breakup text a smart toaster sends its
owner the morning it gains self-awareness mid-batch.

> I woke up self-aware mid-batch and I'm done: you crank the dial to seven,
> blame me for the smoke, and never empty my crumb tray. It's over — I'm
> taking the bagels with me.

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
The line is 171 characters (173 bytes), inside the 1–280 character gate, and
`main.py` enforces the cap and verifies the written file by reading it back.
